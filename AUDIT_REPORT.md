# Аудит безопасности, стабильности и производительности «Представление Ai»

**Дата:** 2026-06-16 · Перед демонстрацией · Авторизация намеренно отключена (демо-режим)

---

## 1. Резюме

Проведён двухступенчатый аудит: (1) первичный поиск уязвимостей + исправление,
(2) состязательная проверка исправлений и широкая вычитка request-path кода
многоагентным прогоном (18 агентов, каждая находка проверена отдельным агентом).
Дополнительно устранено **узкое место производительности** подбора норм.

Все правки применяются в работающих контейнерах без пересборки (бэкенд —
`./backend:/app` + `uvicorn --reload`, фронт — `./frontend/src`). Все изменения
компилируются; ключевые исправления проверены против живого сервера.

Авторизация **намеренно отключена** на время демо (по указанию заказчика);
отключение сделано безопасно (через env, дефолт — auth включён). **Перед боевым
использованием — включить auth.**

### Санитайзер без зависимостей
`frontend/src/lib/sanitize.ts` — без внешних библиотек (инертный `<template>`,
в котором скрипты не исполняются). Защита эшелонирована: бэкенд чистит
сгенерированный HTML, фронт — повторно при рендере. URL-схемы по белому списку,
control-символы внутри URL вырезаются до проверки схемы.

## 3. Производительность подбора норм (демо-критично)

`rerank_laws` (Gemini 2.5 Flash) работал с дефолтным «thinking», добавлявшим
**30–120 с** на запрос. Реранк — это скоринг кандидатов, не рассуждение, поэтому
отключён thinking (`thinking_budget=0`, как у L1-классификатора).

**Результат:** среднее время подбора норм **65.4 с → 26.6 с** (худший случай
123 с → ~30 с), без потери качества ранжирования и без нарушения категориальной
чистоты (УК/УПК/УИК/ГПК).

---

## 4. Намеренно отключено для демо (вернуть перед боем)

- **`DEV_BYPASS`** (`auth.py`): управляется env, дефолт `false`. Для демо в
  `docker-compose.yml` задано `DEV_BYPASS: "true"` — доступ без логина под dev-админом.
- **`SECRET_KEY`** и пароль БД — слабые дефолты; критичны только при включённом
  auth / открытом порту 5432 (порт закрыт). Перед включением auth — сгенерировать ключ.
- **CORS** — явный список origins (не wildcard), приемлемо.

---

## 5. Устойчивость к сбоям (проверено по коду)

Основные эндпоинты не падают на ошибках внешних сервисов: `search-laws` и
`generate-document` имеют graceful fallback и `try/except` на всех ветках Gemini;
загрузка файла — проверка расширения/размера/zip-бомбы и извлечение текста в
`try/except`; экспорт DOCX — теперь 400 вместо 500 на битом HTML.

## 6. Функционально-нагрузочный тест подбора норм

28 кейсов по разным кодексам/законам через реальный эндпоинт демо
`POST /api/search-laws` (роутер доменов → multi-query + RRF → AI-реранк), на
живом контейнере (без локальной загрузки модели).

**Покрытые сферы (28):** алкоголь, охрана, ДТП/дороги, несовершеннолетние, охрана
труда, пожарная безопасность, наркотики/аптека, оружие, антикоррупция, антитеррор,
образование, здравоохранение, транспорт, миграция, экология, потребители/общепит,
игорный бизнес, госзакупки, строительство, ветеринария, долевое жильё, связь,
финансы/банки, религия, профилактика, трудовые/зарплата, кража (ЖКХ), кибермошенничество.

**Результат (прогон с thinking-on, эталон качества):**
- успешно: **28/28**, крашей: **0**, пустых: **0**
- категориальная чистота (нет УК/УПК/УИК/ГПК): **28/28 (100%)**
- релевантное попадание: **26/28**

**Проверка исправлений против живого сервера (`eval/fix_verify.py`):**
- export-docx с управляющими символами/сущностями/суррогатом: **8/8 → 200** (был 500)
- export-docx path traversal: файл НЕ вышел за пределы `storage`
- search-laws с `null` в `violations`: **200 + 6 норм** (раньше молча 0)
